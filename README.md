# NOORINVITES_ROYALHERITAGE

A custom, fully-localized royal Indian wedding invitation based on the Rajwada template by Naqsh Digital.

## Customizations Applied
1. **Asset Recovery**: All HTML, CSS, JS, Fonts (.woff2), Images, MP4, and MP3 files are fully downloaded and localized to ensure zero external dependency (offline/local deployment ready).
2. **UI Cleanup**: The "Demo Version" badge and "Create Yours" CTA modal and scripts have been fully removed.
3. **Content Customization**: 
   - Tailored for Ms. Abhilasha Dhabarde & Mr. Rahul Sahakate.
   - Dynamic short-name implementation and stacked event date/time schedule.
   - Updated Venue to "Kalode Lawn, Hinganghat".
   - SEO tags (`title`, `description`, `og:`) point to the couple.
4. **Audio & Media**: Localized ambient audio and intro assets with responsive countdown and scratch reveal.

## Deployment
Since all assets are local, this can be seamlessly pushed to Vercel, Netlify, or any static hosting provider.
